# 阿米娅桌宠 · Amiya Desktop Pet

Windows 桌面舞蹈宠物。黑、蓝、白的切角菜单，透明背景，可拖动、暂停、调整大小和切换原声。独立运行，不依赖 GPT、Python 或联网服务。

## 下载和使用

在本仓库 Releases 中下载 `AmiyaPet-Blue.exe`，双击运行。适用 64 位 Windows 10 / 11，使用 Windows 自带的 .NET Framework 4.x。

- 左键拖动角色；双击暂停或从头继续。
- 右键打开控制菜单：音乐开关、暂停、重播、大小、置顶、移回屏幕、退出。
- 默认静音；音乐与动画使用相同片段，循环时重新对齐。
- 原视频已经裁掉的部分兔耳、腿部仍保留原样，循环处可能出现原片段跳切。

## 从源码构建

需要 Windows 自带 .NET Framework C# 编译器。程序运行无需额外安装 Python。

1. 从 Release 下载 `AmiyaPet-assets.zip`，解压至仓库的 `assets` 文件夹；内应有 `frames.zip` 与 `music.wav`。
2. 在 PowerShell 中运行 `./build.ps1`。
3. 成品为 `dist/AmiyaPet-Blue.exe`。动画与音乐均嵌入单个 EXE。

也可使用自己有权使用的视频重新生成素材：

```powershell
./tools/Prepare-Assets.ps1 -Video 'D:\video.mp4' -FFmpeg 'D:\ffmpeg.exe'
./build.ps1
```

默认截取 6 秒至 32.6 秒。抠图规则针对本项目视频的浅绿色背景，不是通用视频抠图工具。背景删除仅使用边缘连通色域，角色封闭轮廓内的颜色尽量保留。

## 验证

```powershell
./dist/AmiyaPet-Blue.exe --check check.txt
```

## 文件

- `src/Pet.cs`：桌宠播放、音频及桌面操作。
- `src/Theme.cs`：黑蓝白菜单样式。
- `tools/Prep.cs`：透明帧生成工具。
- `tools/Prepare-Assets.ps1`：片段截取与素材处理。
- `build.ps1`：编译与资源嵌入。
